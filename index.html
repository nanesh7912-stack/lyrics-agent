How to set up the token
  1. Open GitHub’s token settings and create a fine-grained personal access token.
  2. Under repository access, select Only select repositories, then choose lyrics-agent-renders.
  3. Under repository permissions, set Contents to Read and write. No Actions permission is needed.
  4. Generate the token, return here, paste it once, and upload. The page reuses it in this tab and clears it when you close or reload the tab.

Privacy

When you upload, this page sends audio directly from your device to the private lyrics-agent-renders GitHub repository. The page keeps your GitHub token in memory for this open tab and sends it only to GitHub for uploads; it clears the token when you close or reload the tab. No separate upload service is used. The email button opens your email app.

Terms

Only upload songs you have permission to use. Each finished video and its review files are kept in a private GitHub Release until you delete the release or repository. The temporary Actions artifact expires automatically.
